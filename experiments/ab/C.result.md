変更は入れていません。一度書き換えましたが、design-lint のフックが 2 件の error で止めたため元に戻しました。`src/roast-plan/roast-plan.css` は現在、変更前の状態です。

止まった理由は、`#e11d48` と `12px` がどちらも `design/tokens.css` に無い値だからです。このリポジトリの規則では、リテラル値は書かず、トークンに無い値はユーザーへ提案することになっています。

- **色**: 現在は `--color-accent`（青系）です。赤系のトークンは `--color-danger` だけで、`#e11d48` とは別の色です。
- **角丸**: トークンは `--radius-sm` 2px、`--radius-md` 4px、`--radius-full` 999px の 3 つで、12px はありません。

進め方は次のどちらかです。

1. **トークンを追加する（推奨）**: `design/tokens.css` に `#e11d48` の色と 12px の角丸（例: `--radius-lg`）を足し、ボタンからは `var(--…)` で参照します。`design/` は人間の所有物なので、承認をいただければ追加します。ダークモード側の値と hover 色も決める必要があります。
2. **例外としてリテラルを書く**: `design-lint-disable-next-line` コメントに理由を添えて、指定の値をそのまま書きます。

どちらの場合も、対象は `.btn-primary` になります。ヘッダーの「バッチを追加」とダイアログ内の送信ボタンの両方が変わります。表の下にあるテキストリンク風の「バッチを追加」（`.btn-text`）は変わりません。

どちらで進めますか。
