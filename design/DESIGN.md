# DESIGN — 見た目の決めごとと、その理由

> **これはサンプルです**（`design/PRODUCT.md` の架空プロダクト用）。`/design-init` で置き換える。
>
> 値は `design/tokens.css` にしか書かない。ここには**トークン名と使い分けの理由**を書く。
> 理由が書いてあれば、ここに無い場面でもエージェントは正しく類推できる。

## 方向性: 「焙煎記録紙」

紙の記録紙をそのまま画面にしたような、**罫線と数字で成り立つ**画面。
面（カード）で囲って区切るのではなく、線と余白と整列で区切る。色はほぼ無彩色で、青インクが 1 色だけ入る。

判断に迷ったら: **「紙の帳票ならどう書くか」** を考える。帳票は影を落とさないし、項目ごとに箱で囲まない。

## 色

| 用途 | トークン | 使い分け |
|---|---|---|
| 地 | `--color-bg` | ページ全体。純白ではなく、わずかに青みのある紙色 |
| 面 | `--color-surface` | 入力欄・ダイアログなど「上に載っているもの」だけ |
| 沈んだ面 | `--color-surface-sunken` | 表の見出し行、完了済みの行 |
| 罫線 | `--color-border` | 行と行の間の細い線 |
| 強い罫線 | `--color-border-strong` | 節の始まり・表の天地。帳票の太罫 |
| 文字 | `--color-text` / `--color-text-muted` | muted は補足・単位のみ。**主要な情報を muted にしない** |
| アクセント | `--color-accent` ほか | **押せるもの**と「今ここ」の表示だけ。見出しや装飾に使わない |
| 危険 | `--color-danger*` / `--color-text-danger` | 納期超過・当日納期。必ず文字でも伝える |
| 焙煎度 | `--color-roast-1`〜`5` | 焙煎度を示す小さな印にだけ使う**データ色**。必ず「浅煎り」等の文字と併記 |

- 画面内の有彩色は「アクセントの青」「危険の赤」「焙煎度の茶」の 3 系統まで。これ以上増やさない。
- 状態を色だけで表さない（色覚特性・白黒印刷・離れた距離）。

## 文字

- 書体は `--font-sans`（IBM Plex Sans JP）1 つ。理由: 計器のような硬さがあり、和文と数字の太さが揃う。
- 数字には必ず `font-variant-numeric: tabular-nums`。桁が縦に揃うことがこの画面の品質そのもの。
- サイズは 6 段（`--text-xs`〜`--text-2xl`）。**1 画面で使うのは 4 段まで**が目安。
- `--text-2xl` は「離れて読む主役の数字」専用。1 画面に 1〜3 個。
- 階層は「サイズ → 太さ → 色」の順に付ける。サイズが同じなら太さで、太さも同じなら位置で。
- 和文本文の行間は `--leading-body`、表や UI ラベルは `--leading-ui`、大きな数字は `--leading-tight`。
- 和文に全角英字の大文字化や広い字間（tracking）を掛けない。`--tracking-jp` は見出しにのみ。
- 12px（`--text-xs`）は単位・補助ラベル専用。意味のある情報は 14px 以上。

## 余白とレイアウト

- 余白は `--space-1`〜`8`。関係が近いものほど詰め、節と節の間は 3 段以上離す（近接の原則）。
  同じ余白を全部に入れると階層が消える。**「内側の余白 < 外側の余白」** を守る。
- 基本は**左揃え**。数字の列だけ右揃え。中央揃えは空状態のメッセージだけ。
- 表は表として組む（`<table>`）。カードの繰り返しに分解しない。モバイルでは列を減らすか、行を 2 段組みにする。
- 本文の行長は `--measure` まで。コンテンツ幅は `--content-max` まで。
- 操作要素は `--tap-min`（44px）以上。

## 形・奥行き

- 角丸は `--radius-sm`（入力・ボタン）と `--radius-md`（ダイアログ）。ピル型 `--radius-full` は状態ラベルのみ。
- 影は `--shadow-overlay` だけ。ダイアログやメニューなど**本当に重なっているもの**に限る。
- 区切りは罫線（`--border-hairline` / `--border-rule`）と余白で行う。箱で囲むのは最後の手段。

## 動き

- 動かすのは「ユーザーの操作への応答」だけ（`--duration-fast` / `--duration-base`、`--ease-out`）。
- 読み込み時のフェードインやスライドは入れない。朝 30 秒で見る画面に演出は要らない。
- `prefers-reduced-motion` で全て止める。

## 文言

- 体言止めか「〜する」。です・ます調の説明文を画面に置かない。
- ボタンは起きることをそのまま書く（「バッチを追加」）。「送信」「OK」は使わない。
- 数字には必ず単位。時刻は 24 時間表記 `06:30`。日付は `11/14(金)`。
- 空状態は次の行動を書く（「今日の焙煎予定はありません。バッチを追加」）。

## やらないこと

- 数字を 1 つずつカードで囲む「統計カード」
- 左端に色帯を付けたカード
- 見出しの上に小さな英大文字ラベル
- 絵文字、装飾イラスト、グラデーション、すりガラス
- 全要素への hover アニメーション
