# 和文 UI の要点

欧文前提の既定値をそのまま使うと、和文は窮屈で読みにくくなる。

- `<html lang="ja">` を必ず付ける（字形の選択・禁則・読み上げが変わる）
- 行間: 本文 1.7〜1.9、UI ラベルや表 1.4〜1.5、大きな見出し・数字 1.2〜1.3。欧文の定番 1.5 は本文には狭い
- 行長: 本文は全角 35〜40 字（`max-width: var(--measure)`）。45 字を超えると次の行頭を見失う
- 太さ: 和文フォントは 400 と 700 の差が欧文より小さく見える。階層は太さよりサイズで付ける。
  300 以下の細いウェイトは小さいサイズで使わない
- 字間: 本文は詰めも開けもしない。見出しだけわずかに開ける（`--tracking-jp`）。
  英大文字 + 広い字間の小ラベルは和文 UI では浮く
- 斜体は使わない（和文に斜体は無く、機械的に傾くだけ）
- 最小サイズは 12px。意味のある情報は 14px 以上（画数の多い漢字が潰れる）
- 改行: 見出しやボタンは `text-wrap: balance` / `word-break: auto-phrase`（対応ブラウザ）で文節改行。
  ボタン文言は折り返させない（`white-space: nowrap`）
- 約物: 行頭の「（」「」などの空きが気になる見出しは `font-feature-settings: "palt"` を**見出しにだけ**。
  本文や表の数字に `palt` を掛けると桁がずれる
- 数字と単位: 数字は `tabular-nums`。単位（kg、件）は数字より一段小さく、間に細い空き
- 全角/半角: 数字・英字は半角。括弧は和文中なら全角
- フォント指定は和文フォントを含むスタックで、最後に総称。Web フォントは `font-display: swap` と
  必要ウェイトのみ（和文フォントは重い。3 ウェイトまで）
