# 生成 UI の「癖」と、その代わりにすること

これらは「禁止」ではなく**無自覚なデフォルト**。DESIGN.md が明示的に求めているなら従ってよい。
求められていないのに出てきたら、それは選択ではなく惰性なので直す。
禁止リストを避けただけで別の定番に流れるのも同じ失敗 — 判断の根拠は常に PRODUCT.md / DESIGN.md に置く。

## ありきたりに見える原因

| 癖 | なぜ起きるか | 代わりに |
|---|---|---|
| 何でも角丸カードで囲み、同じ影を付ける | 区切りを考えずに済むから | 余白・罫線・整列で区切る。囲むのは「まとまりとして操作する物」だけ |
| 数字ごとの統計カード 3〜4 枚の横並び | ダッシュボードの定型 | 主役の数字 1 つを大きく、残りは 1 行の文や表に |
| 紫〜青のグラデーション、光る影、すりガラス | 「モダン」の平均値 | DESIGN.md の色。無彩色 + アクセント 1 色から始める |
| Inter / Roboto / システムフォント任せ | 既定値 | `--font-*`。和文は japanese.md |
| 絵文字アイコン、✨🚀 | 手軽な装飾 | 文字だけにする。必要なら線の SVG アイコンを 1 系統で |
| 見出しの上の小さな英大文字ラベル、`01 / 02 / 03` の番号 | テンプレ装飾 | 情報を持たないラベルは削る。番号は本当に順序があるときだけ |
| 見出しの一語だけ色や書体を変える | 「強調」の定型 | 強調はサイズと太さの階層で |
| 左端だけ色帯のカード | 状態表示の定型 | 状態は文字ラベル + 位置で |
| 全部中央揃え | 整列を考えずに済む | 左揃えが基本。数字は右揃え |
| 全要素にフェードイン・hover で浮く | 「動きがある＝高品質」の誤解 | 動きは操作への応答だけ |
| クリーム地 + テラコッタ + セリフ見出し / 黒地 + 蛍光色 | 「紫を避けた」ときの次の定番 | 同上。プロダクトの世界から決める |
| 「ようこそ」「今すぐ始めましょう」などの汎用コピー | 中身が無いまま組むから | 実データ・実際の操作名で書く |

## 見にくくなる原因

| 癖 | 代わりに |
|---|---|
| 薄いグレーの小さな文字（12px・コントラスト 3:1 台） | 意味のある情報は 14px 以上・`--color-text`。muted は補足だけ |
| 文字サイズが 8 種類以上ある | 1 画面 4 段まで。差は 1.25 倍以上付ける。近いサイズを並べない |
| 全部が同じ強さ（全部太字、全部カード、全部に色） | 主役を 1 つ決め、他を意図的に弱める |
| 余白が全部同じ（どこも 16px） | 関係が近いものは詰め、節の間は 3 段以上空ける |
| 色だけで状態を伝える | 文字ラベルを併記 |
| 表をカードの繰り返しに分解 | 比較する情報は表のまま。列を揃える |
| 数字が左揃え・プロポーショナル | 右揃え + `tabular-nums` + 単位 |
| 行長が長すぎる（和文 45 字超） | `max-width: var(--measure)` |
| 短いダミーでしか確認していない | 最長の名前・0 件・最大件数で組む |
| ボタンが全部同じ見た目 | 主操作は 1 画面 1 つ。他は一段弱く |
| フォーカスリングを消す、タップ領域が小さい | `:focus-visible` を必ず見せる。44px 以上 |
| placeholder をラベル代わりにする | `<label>` を常に表示 |
